## 📚 Ուսումնական ծրագիր
> ⚠️ **Ուշադրություն․** Ստորև ներկայացված է դասընթացի հիմնական թեմաների ցանկը։ Յուրաքանչյուր թեմա ներառում է մեկից ավելի դաս։ Թեմաների մանրամասն բովանդակությունն ու գործնական աշխատանքները քննարկվում են դասընթացի ընթացքում։

<br>

### 🟢 Մակարդակ 1. հիմունքներ

#### Linux / Ubuntu․ հիմունքներ

- Օպերացիոն համակարգի տեղադրում
- Ծանոթացում համակարգին
- Ֆայլային համակարգ
- Համակարգչից առողջ օգտվելու սովորություններ

#### Աշխատանքային միջավայր

- Հաղորդակցման միջոցներ
- Առաջադրանքներ և տնային աշխատանք

#### Աշխատանք ֆայլերի և թղթապանակների հետ

- Ֆայլերի և թղթապանակների ցուցադրում
- Թղթապանակների միջև տեղաշարժ(նավիգացիա)
- Որոնում և ֆիլտրում

#### Կոդի խմբագրիչ․ հիմունքներ

- Vim և Neovim
- Հիմնական խմբագրում
- Ռեժիմներ
- Տեղաշարժ
- Օպերատորներ և շարժումներ
- Ստեղնաշար և կույր տպագրություն

#### Git. հիմունքներ

- Պահոց
- Հիմնական հրամաններ
- Commit
- Հեռակա պահոցներ

#### Shell սկրիպտավորում

- Պարզ սկրիպտների ստեղծում
- Փոփոխականներ և արգումենտներ
- Պայմաններ և ցիկլեր
- Սկրիպտների գործարկում

#### Ավտոմատացում

- Կրկնվող գործողությունների ավտոմատացում
- cron և պլանավորված առաջադրանքներ
- Սկրիպտների համատեղում պլանավորված գործարկման հետ

#### Python. հիմունքներ

- Փոփոխականներ և տիպեր
- Ներկառուցված տվյալների կառուցվածքներ
- Պայմաններ և ցիկլեր
- Ֆունկցիաներ
- Աշխատանք ֆայլերի հետ
- Կոդի ոճ, ձևաչափ և որակ

#### Ծրագրավորման միջավայր

- IDE
- Նախագծի կառուցվածք
- Նախագծի ստեղծում
- Python վիրտուալ միջավայր
- Կախվածություններ
- Միջավայրի փոփոխականներ

### 🟡 Մակարդակ 2․ Միջին

#### Python

- Ծրագրավորման պարադիգմաներ
- Օբյեկտկողմնորոշված ծրագրավորում
- Մոդուլներ, փաթեթներ և գրադարաններ
- Բացառություններ և սխալների մշակում
- Մեկնաբանություններ և փաստաթղթավորում
- Փաթեթների կառավարիչներ

#### Git

- Ճյուղավորում
- Միավորում
- Pull request-ներ
- Կոդի վերանայում (review). հիմունքներ
- Այլ ծրագրավորողների կոդի ընթերցում

#### Տվյալների բազաներ

- Տվյալների բազաների տեսակներ
- SQL-ի հիմունքներ
- PostgreSQL
- CRUD գործողություններ
- Տվյալների բազայի նախագծում
- Նորմալացում

#### Ալգորիթմներ

- Որոնում
- Տեսակավորում
- Ալգորիթմների բարդություն
- Տվյալների կառուցվածքներ․ խորացված

#### Ծրագրավորողի գործիքներ

- CLI գործիքներ
- Կոդի կարգաբերում
- Թեստավորում
- Գրանցամատյանների վարում

### 🔵 Մակարդակ 3․ Backend ծրագրավորում

#### Վեբ տեխնոլոգիաներ

- HTTP. հիմունքներ
- API-ներ
- REST

#### Ֆրեյմվորքեր

- Django (հիմնական ուղղություն)
- Flask

#### Նույնականացում և անվտանգություն

- Սեսիաներ
- Թոքեններ
- Անվտանգության հիմունքներ

#### Նախագծի ճարտարապետություն

- Հավելվածի կառուցվածք
- Պարտականությունների տարանջատում
- Ճարտարապետական մոտեցումներ
- Կարգավորումների և միջավայրի կառավարում
- Մասշտաբավորման հիմունքներ

### 🟣 Մակարդակ 4․ Աշխատանքային գործընթաց

#### Թիմային աշխատանք

- Agile. հիմունքներ
- Առաջադրանքների կառավարում
- Աշխատանք զույգերով

#### Աշխատանքային միջավայր

- Մասնագիտական հաղորդակցություն
- Փաստաթղթավորում
- Ծրագրային ապահովման լիցենզիաներ

#### Դերերը ՏՏ ոլորտում

- Դերերը ծրագրավորման թիմում
- Մասնագիտական մակարդակներ և պարտականություններ
- Մասնագիտական զարգացում

#### Արհեստական բանականություն. AI

- Ի՞նչ է ԱԲ-ն և ինչպե՞ս է այն աշխատում
- Արհեստական և բնական բանականություն
- Ե՞րբ և ինչպե՞ս օգտագործել ԱԲ-ն
- Ծրագրավորում ԱԲ-ի օգնությամբ
- Vibe coding-ը և դրա ռիսկերը
- ԱԲ գործիքներ ծրագրավորողների համար
- Էթիկա և պատասխանատու օգտագործում
